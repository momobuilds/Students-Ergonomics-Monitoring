Sensor Fusion Model Validation
==============================

Validation notes:
- Macro F1 matters more than plain accuracy because each wellbeing class should count, even when Good and Warning are more common.
- Critical recall matters because missing a Critical state is more costly than raising an occasional false alarm.
- The final test split is subject-based so the model cannot benefit from seeing the same student in both training and testing.
- Critical threshold tuning uses validation subjects only. The test set is used once for the final selected model.
