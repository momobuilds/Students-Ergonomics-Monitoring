NO HR/RMMSD SUPERVISED LOSO EXPERIMENT SUMMARY
================================================================================
Two scenarios were tested. The realistic no-heart-sensor scenario trains and tests using only posture + eye/blink features. The masked-test scenario trains with all features but sets HR/RMMSD to missing in each held-out test fold, so the training-fold imputer fills them.

Scientific recommendation: use the no_hr_rmmsd_train_test scenario for claims about a missing heart-rate sensor. Training with HR/RMMSD and then masking them at test time is a deployment-mismatch stress test, not the preferred production setup.
