================================================================================

Date: 2026-06-08 11:00:45
Model: Gaussian Mixture (sklearn.mixture.GaussianMixture, covariance_type='full').
Pipeline: SimpleImputer(median) + StandardScaler + Gaussian Mixture, fit ONLY on the training subjects of each LOSO fold.
Cross-validation: Leave-One-Subject-Out on group column = video_source.
Tasks: binary (normal vs anomalous, n_components=2) and direct_3class (normal/sleepy/stress, n_components=3).
Method: per fold, cluster the training subjects with Gaussian Mixture; freeze a cluster -> label mapping by majority vote on the training assignments (a component with no training rows falls back to the most frequent training label); then apply that frozen mapping when predicting the held-out subject. This mirrors how the offline-trained GMM in the GUI labels real-time data from subjects it has never seen.
Random state: 42.

Sensor groups:
  - Posture (camera body): 9 features -> p_shoulder_mean, p_shoulder_std, p_shoulder_bad_pct, p_head_tilt_mean, p_head_tilt_std, p_head_tilt_bad_pct, p_fhp_mean, p_fhp_std, p_fhp_bad_pct
  - Blink   (camera face): 7 features -> b_ear_mean, b_ear_std, b_perclos, b_blink_count, b_blink_freq, b_ibi_mean, b_ibi_std
  - Heart   (wearable)   : 2 features -> HR, RMMSD

Scenarios:
  full   : fit and predict using all 18 features. Reference baseline per task.
  clean  : fit and predict using only the features of the kept sensors. The realistic 'we just don't have this sensor' setup the GUI would face. This is the trustworthy scenario for the ablation.
  masked : fit with all 18 features on the training subjects, then set the excluded-sensor columns to NaN on the held-out subject so the training-fold SimpleImputer fills them with the training median. Deployment-mismatch stress test, reported only for analysis/comparison.
